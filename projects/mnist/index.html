Under the hood

A small model.
A real ML pipeline.

The drawing travels to a hosted Python API. It is cropped, centered, and resized to 28 × 28 pixels before a convolutional neural network makes its prediction.

ModelConvolutional neural network

Ten digit classes and one learned rejection class.

TrainingMNIST + rejection examples

Handwritten digits, EMNIST letters, and generated multi-digit drawings, shapes, and scribbles.

EvaluationHeld-out test results

Validation selects the model and thresholds. Separate test sets measure digit accuracy and rejection performance.

LimitationsRejection is a judgment call

The model can still mistake a doodle for a digit or reject unusual handwriting. Confidence is a model score, not a guarantee.
